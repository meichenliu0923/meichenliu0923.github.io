# 刘美辰 · 作品集网站

个人作品集站点 —— 品牌营销 / 海外社媒矩阵 / 内容创作。

## 技术栈

纯静态站点，零依赖、零构建：

- `index.html` — 页面结构
- `styles.css` — 样式（CSS 变量设计系统、响应式、深色排版、打印样式）
- `script.js` — 交互（滚动进度、进场动画、数字滚动、导航高亮、移动端菜单）

## 本地预览

直接双击 `index.html`，或启动本地服务：

```powershell
python -m http.server 8000
```

然后访问 http://localhost:8000

## 部署

托管在 GitHub Pages，推送即自动发布。

## 说明

纯静态站点，内容整理自个人简历。出于隐私考虑，页面中不包含手机号、邮箱等个人联系方式，唯一对外入口为 GitHub 主页。
